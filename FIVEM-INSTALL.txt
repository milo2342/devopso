WCRP FiveM Verification Resource v1.2

1. Put fxmanifest.lua and fivem-server.lua inside your existing wcrp_verification resource folder.
2. In server.cfg keep these lines, replacing ONLY the secret placeholder with the same private secret stored in Railway:

set wcrp_verification_url "https://devopso-production.up.railway.app/api/fivem/connect"
set wcrp_verification_secret "YOUR_PRIVATE_SECRET"
ensure wcrp_verification

3. Restart the FiveM server/resource.
4. Never put the secret in a client script or share it publicly.

The resource reports server-side Discord/license identifiers when a player connects. On playerDropped it reports the disconnect reason to /api/fivem/disconnect. The bot keeps the session start time so disconnect logs can include session length.

Discord setup (two independent channels):
/verification connect-logs channel:#your-connect-channel
/verification disconnect-logs channel:#your-disconnect-channel

Optional disable commands:
/verification connect-logs-off
/verification disconnect-logs-off

You may point both commands at the same channel if you ever want combined logs again.
