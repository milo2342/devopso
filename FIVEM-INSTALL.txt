WCRP FiveM Verification Resource v1.3

1. Replace your existing fivem-server.lua with the file included in this build.
2. Keep your normal server.cfg values:
   set wcrp_verification_secret "YOUR_CURRENT_SECRET"
   set wcrp_verification_url "https://YOUR-BOT.up.railway.app/api/fivem/connect"

The v2.11.0 bot requires replay-protection fields generated by the updated Lua resource.

ZERO-DOWNTIME SECRET ROTATION
1. Put the new key in Railway as FIVEM_VERIFICATION_SECRET_NEXT.
2. Update wcrp_verification_secret on FiveM to the new key and restart the resource/server.
3. Confirm connect/disconnect calls work.
4. Promote the new key to FIVEM_VERIFICATION_SECRET and clear FIVEM_VERIFICATION_SECRET_NEXT.

The backend rejects duplicate request IDs, stale requests older than 2 minutes, and excessive request rates.
