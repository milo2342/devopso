WCRP FiveM Verification Resource

1. Copy the wcrp_verification folder into your FiveM resources folder.
2. In server.cfg add these lines, replacing ONLY the secret placeholder with the same private secret stored in Railway:

set wcrp_verification_url "https://devopso-production.up.railway.app/api/fivem/connect"
set wcrp_verification_secret "YOUR_PRIVATE_SECRET"
ensure wcrp_verification

3. Restart the FiveM server/resource.
4. Never put the secret in a client script or share it publicly.

The resource reads the server-side Discord and license identifiers when a player joins and reports them to the Dev Ops verification API.
